## Deliberate packaging changes

- New command-line entry point and explicit JSON plan expansion replace Colab globals, runtime setup, `%%writefile`, action string scripts and notebook-only monkey patches.
- Source computational functions were moved into modules. The model's `net`/`head` state keys and tensor shapes remain unchanged.
- The saved INCART split is read as a fixed artifact rather than generated by scikit-learn; all record assignments and the original data ID are preserved.
- Canonical configs override stale defaults. Unsupported legacy record splits, unmapped-positive targets, GroupNorm architecture and legacy imbalance schedules are rejected/not exposed.
- D2 results are summarized across seeds. Old cluster/window bootstrap utilities are excluded from manuscript execution.
- The new package hashes its own code, producing new run IDs. It never substitutes the historical code hash into new runs.
- Full source notebooks, extracted original engine, historical result stages and retrieved evidence remain separately archived. New output roots are independent of original Drive folders.

Authored CLI/reporting code is new integration code based on the recovered protocol, not evidence that an unobserved historical script existed. Source parity validation is reported separately from end-to-end scientific reproduction.
